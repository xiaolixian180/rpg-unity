# Hero Quest Roadmap

## Phase 0 - Foundation

- Project structure and Git hygiene.
- Testable stat, combat, and dungeon rules.
- Bootstrap/service boundaries.
- Placeholder network contract.

## Phase 1 - Local Playable Loop

- Player spawn and movement.
- One dungeon layer with monsters and resources.
- Basic attack loop and reward payout.
- Minimal HUD for HP, level, exp, gold, and selected target.

## Phase 2 - Data-Driven RPG Systems

- Character classes and skills.
- Equipment slots, quality, strengthen, enchant, and equip rules.
- Pets and collection resources.
- ScriptableObject or external table import workflow.

## Phase 3 - Online Systems

- WebSocket session lifecycle.
- Server-authoritative combat and collection actions.
- PvP room flow.
- Trading/marketplace flow.
